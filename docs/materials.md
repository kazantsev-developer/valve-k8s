# База знаний

Каталог учебных материалов, официальной документации и ключевых источников исследования.

## Курс обучения и лекционные материалы

- **[Платформа курса "Контейнеризация и оркестрация"](https://frogs.inview.team/index.html)** - Единый лекционный ресурс теоретической базы ИТМО.

### Программа исследования до ноября 2026:

- Внутреннее устройство контейнеризации (ядерные механизмы namespaces, cgroups v2, рантайм-стек OCI слоев).
- Построение сквозной наблюдаемости систем: сбор RED-метрик, структурированных JSON-логов и распределенной трассировки.
- Кишки Kubernetes Control Plane: база etcd как единственный источник правды, kube-apiserver, оптимистичная блокировка через resourceVersion и циклы сверки (reconciliation loop).
- Планирование и ресурсы: глубокий разбор механики работы requests и limits, профили QoS, причины возникновения аварий OOMKilled и процессорного троттлинга (CPU Throttling).
- Сетевой датаплейн оркестратора: плоская сеть подов, CNI-плагины, виртуальные адреса ClusterIP (iptables против IPVS) и NetworkPolicy.
- Архитектура Service Mesh: L7-проксирование трафика через sidecar-контейнеры Envoy, взаимная аутентификация mTLS и identity.

## Исследования FinOps и автоматизации ресурсов

- **[Natan Yellin (Robusta) — Stop using CPU limits on Kubernetes](https://robusta.dev)** - Анализ деградации latency приложений из-за CPU Throttling при использовании лимитов процессора.
- **[Репозиторий Robusta KRR](https://github.com)** - Открытый код инструмента формирования рекомендаций по лимитам ресурсов на основе Prometheus.

## Официальные спецификации и документация

- **[Kubernetes API Reference](https://kubernetes.io)** - Официальная документация по работе с API-сервером, манифестами объектов и типами данных.
- **[Kubernetes In-place Pod Resource Resize](https://kubernetes.io)** - Спецификация API для изменения requests и limits на лету без перезапуска контейнеров.
- **[The Go Programming Language Documentation](https://go.dev)** - Справочные материалы по языку Go, работе с конкурентностью, планировщиком горутин и профилированием.
- **[Библиотека Cilium eBPF для Go](https://github.com)** - Инструментарий загрузки BPF-программ и взаимодействия с BPF-картами ядра Linux.
